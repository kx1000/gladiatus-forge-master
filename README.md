# Gladiatus Forge Master

An unofficial Gladiatus add-on that gives you powerful tools for resource collecting and forging — perfect for players above level 80.

## Features

- Scroll search functionality + stats preview
- Quick preview of materials required for forging
- Package items resource preview
- Forge resource planner
- Horrerum resources values estimation
